# Executable Brownian laboratory preview

This repository now contains a working Next.js App Router application, not just
plans. This preview does not constitute the complete reviewed edition, complete
BM-06 bead, full runtime contract, or a production deployment.

## Read and run

- `/` introduces the available preview without claiming the edition is finished.
- `/papers/` distinguishes the four planned papers from the available laboratory.
- `/discover/brownian-motion/` is an authored no-algebra encounter with displacement,
  independent steps, interval probability and the distinction between model and evidence.
- `/lab/bm-06/` is the interactive spreading laboratory.

The following commands were exercised by the preview workflow under Node 22.16.0:

```sh
npm install --ignore-scripts --no-audit --no-fund
npm run test:reference
npm run typecheck
npm run build
npx playwright install --with-deps chromium
npm run test:browser
```

`npm run dev` generates the same worked example before starting the development
server. The production build exports static pages to `out/`. Do not use this
preview workflow to promote a production release; the verified release workflow
and deployment checks remain separate work. Git-triggered Vercel deployment stays
disabled. The ratified Node 22.13.4/Bun toolchain is not claimed verified by the
Node 22.16.0 run, and a committed dependency lock remains outstanding.

## What the laboratory implements

Temperature, viscosity, radius, elapsed time and a closed interval are typed
controls. A numerical grid is optional. Presets edit a draft; applying settings
explicitly starts a lazy dedicated worker. Graph, table, accepted-setting labels
and comparison values share one immutable accepted snapshot. Refusals preserve
it and offer executable repairs. Stopping or unmounting releases the worker.

A second instance has its own state and worker. Interval-only edits reuse the
identified numerical field. Decimal unit conversion preserves unchanged physical
inputs exactly, so a display roundtrip cannot spuriously restart a run. Shared
links contain accepted SI settings, are strictly validated, and load only a draft:
opening a link never starts a calculation or relabels the static example.

All numeric model values come from `src/physics/reference/`, assembled by
`src/workers/operations/bm06.ts`; components only format or plot those values.
The worker protocol validates identities, revisions, source digest, owners, units,
statuses and array shapes. Requests are coalesced, work is deterministically
bounded, and cancellation happens between numerical chunks. A source digest is
generated from the evaluator dependency closure. These are scoped host-reference
contracts, not an assertion of full FrankenSim protocol conformance.

The initial example is generated by those same owners at build time and validated
before rendering. JavaScript-free HTML includes its graph, values, model notes,
and KaTeX with MathML. No worker starts during hydration.

## Verified evidence and limits

At commit `2cdb478312422cc81cb9cef431b6d5cec3cf8c7e`, GitHub Actions run
`35043728945`, job `104628955933`, passed all 109 reference tests with no skips,
the strict full-application typecheck, the optimized Next.js static build, and
all eight Chromium browser checks. The browser checks covered no-JavaScript
reading and mathematics at 320 pixels, hydration without a worker, accepted-state
parity, refusal/repair recovery, interval remeasurement, independent instances,
an automated accessibility supplement (zero reported violations), and interactive
320-pixel reflow without page errors. Screenshots and structured results are in
that run's `brownian-browser-evidence` artifact. Later commits must be verified
against their own run rather than inheriting this result.

This is **not** a manual screen-reader or disabled-reader review. WebKit, Firefox,
real mobile devices, the publication CSP, verified historical transcriptions,
complete paper reader, all BM-06 modes, audited WASM adoption, stochastic tracer
ensembles, the general content compiler and the broader release gates remain
unfinished. The laboratory labels its modern constants and host computation and
never treats the numerical comparison as observational evidence.
